# Köder-Guide

Web-App: Köder-Empfehlung nach Gewässer, Zielfisch und Bedingungen. Mit Fisch- und Köderlexikon, Gewässerverzeichnis (selbst erweiterbar) und Schonzeiten/Mindestmaßen aller Bundesländer.

- App: `index.html` (läuft offline, auf dem iPhone über Safari › Teilen › „Zum Home-Bildschirm“)
- Daten: `src/fish.js`, `src/baits.js`, `src/waters.js`, `src/regs.json`
- Nach Änderungen in `src/`: `python3 build.py`

Schonzeiten ohne Gewähr (Tabellenstand 09/2021, Quelle fischlexikon.eu). Verbindlich sind der aktuelle Gesetzestext und der Erlaubnisschein.
